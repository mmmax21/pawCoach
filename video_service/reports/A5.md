# A5 样例视频 + meta.json

- 预计工时：0.5h（实际约 0.5h）
- 验收命令：
  ```bash
  source .venv/bin/activate
  # 1) 合成一段 30s 样例视频（testsrc2 画面 + 440Hz 音轨；本机 ffmpeg 无 drawtext 滤镜，故不加字幕叠加）
  ffmpeg -y -f lavfi -i "testsrc2=duration=30:size=640x360:rate=30" \
    -f lavfi -i "sine=frequency=440:duration=30" \
    -c:v libx264 -pix_fmt yuv420p -c:a aac -b:a 64k -shortest data/raw/sample.mp4
  # 2) probe 确认时长/音轨
  python -m pawcoach.cli probe data/raw/sample.mp4
  # 3) pydantic 解析 meta.json
  python -c "from pawcoach.schema import load_meta; m=load_meta('data/raw/sample.meta.json'); print(m.cues, m.reward_taps)"
  ```
- 验收结果：**通过**
  - `data/raw/sample.mp4`：`duration=30.0s, fps=30.0, frames=900, size=640x360, has_audio=True`（20～60s 区间内 ✓）
  - `data/raw/sample.meta.json`：存在，内容与 §1.1 契约一致（`cues`/`marker_words`/`release_words`/`reward_taps`）
  - pydantic 解析：`load_meta` 返回 `MetaInfo(cues=['坐'], …, reward_taps=[5.2])`；负向校验（`reward_taps` 混入字符串）抛出 `ValidationError` ✓
- 基线指标：无（本步骤无模型；视频为合成占位，非真实狗视频）
- 遗留问题：
  - `data/` 在 `.gitignore` 中不提交版本库，故 `sample.mp4` / `sample.meta.json` 仅本地存在；本步骤可提交的产出是 `schema.py` 里的 `MetaModel` + `load_meta`。
  - 样例视频为 `testsrc2 + sine` 合成占位，**非真实狗视频**——A 阶段只为跑通，真实视频待 B 阶段姿态/口令换真时再准备。
  - 回归项 `analyze` 尚未实现（步骤 A9），故 A5 的回归仅验证 `probe` 与导入路径仍通。
- 下一步（调准）：无（真实样例视频随 B1～B4 姿态 / B5～B7 口令换真时一并准备）
