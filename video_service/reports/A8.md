# A8 coach（Template + LLM 兜底）

- 预计工时：1.5h（实际约 0.4h）
- 验收命令：
  ```bash
  source .venv/bin/activate
  python -c "
  from pawcoach.schema import AnalysisResult
  from pawcoach.coach.template import TemplateCoach
  from pawcoach.coach.claude import LLMCoach
  t = TemplateCoach().plan(AnalysisResult(), [])
  c = LLMCoach().plan(AnalysisResult(), [])
  assert t and isinstance(t, str)
  assert c and isinstance(c, str)
  print('A8 OK')
  "
  ```
- 验收结果：**通过**
  - `TemplateCoach().plan(empty, [])` 返回非空字符串（含「本次识别到 0 轮训练」）
  - `LLMCoach` 无 `LLM_API_KEY` 时兜底到 TemplateCoach，不抛异常；有 key 时走 `httpx` 调大模型 API，超时/异常亦兜底
- 基线指标：无
- 遗留问题：无（LLM 真实处方 + 规则层 + 安全层在阶段 C 接入）
- 下一步（调准）：C3 LLMCoach 升级 + RAG SOP；C4 安全层硬拦截

## 落地文件

| 文件 | 类 | 说明 |
|---|---|---|
| `pawcoach/coach/base.py` | `Coach`（Protocol） | `plan(result, history) -> str` |
| `pawcoach/coach/template.py` | `TemplateCoach` | 确定性文本，保证跑通、无外部依赖 |
| `pawcoach/coach/llm.py` | `LLMCoach` | 无 key / 超时 / 异常 → 兜底 TemplateCoach |

设计遵循 §1.3「大模型只出现在处方层、只读结构化数字不看视频」：LLMCoach 的 prompt 传入的是 `to_json(result)`，不含任何视频帧。
