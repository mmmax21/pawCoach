# V3：狗的身体信号（2026-11-23）

## 做什么

从视频（或照片）里测出几种常见的身体信号，交给 App 按内容库 `content/body_signals.yaml` 的规则辅助训练：
练前状态检查、练习中"该停一停"、视频结果里的"狗的状态"、训练节奏建议、周报、需要转介时提示。
服务只测量（`pawcoach/body/signals.py`），不下"开心 / 焦虑"之类的结论；文字全部来自内容库。

## 信号与测法（39 个 SuperAnimal 关键点）

| 信号 | 测法 | 限制 |
|---|---|---|
| 尾巴夹低 | 尾尖沿身体轴往头的方向伸 > 0.6 身长（只看站 / 坐、侧面帧） | 趴着时尾巴常卷到身前，不判 |
| 尾巴高举 | 站姿时尾尖比尾根高 > 0.45 身长 | 只看侧面 |
| 身体压低 | 站姿时爪到背的高度 < 0.7 身长 | 只看侧面 |
| 耳朵往后压 | 耳尖抬起量比这段视频自己的中位数低 0.25 头长以上，持续 ≥1.5 秒 | 照片不判（没有"平时"可比） |
| 张嘴喘气 | 2 秒窗口里张嘴程度 > 0.39 的帧 ≥ 60%，持续 ≥2 秒 | 要看得到嘴 |
| 打哈欠 | 张嘴程度 > 0.68 持续 0.4–3 秒，且不在喘气 | 叼着玩具会误报 |
| 摇尾巴 | 尾尖横向位置 2 秒内来回 ≥3 次、幅度 > 0.25 身长（只看站 / 坐） | 需要每秒 ≥5 帧 |
| 动个不停 | 身体中心速度 > 1 身长 / 秒，持续 ≥1 秒 | 关键点抖动让静止的狗也有约 0.2–0.35 |
| 僵住不动 | 速度 < 0.05 身长 / 秒 ≥2 秒，且同时夹尾巴或身体压低 | 实拍素材里没有出现过，未验证 |

阈值来自 DogPoseCV 约 7300 张标注照片上同一套关键点的分布：站姿腿高第 10 百分位 0.78、尾巴抬起第 90 百分位 0.45、
张嘴第 90 / 97 百分位 0.39 / 0.68。照片含各种机位，分布很宽，阈值是粗的，宁可漏报。

## 实拍复测（Mixkit 素材，按标题分组的弱标签）

`python scripts/v3_eval_body_mixkit.py`（分组见 `tests/fixtures/mixkit_body_groups.json`），每段取前 12 秒、每秒 5 帧：

| 分组（能看清的段数） | 结果 |
|---|---|
| 标题写"panting"（13） | 5 段检出"张嘴喘气"；1 段误报"打哈欠"（叼着球）；1 段误报"尾巴夹低"（趴着的狗被姿势判成站） |
| 标题写"resting / sleeping"（5） | **没有任何信号**（调整前有夹尾巴、摇尾的误报，已把尾巴信号限制在站 / 坐） |
| 标题写"running"（5） | 4 段检出"动个不停"；平均速度 0.47–1.05 身长 / 秒（休息组 0.23–0.36） |
| 标题写"barking aggressively"（4） | 3 段"动个不停"；龇牙看不出来（关键点没有牙齿） |
| "scared in a cage"（1） | 隔着笼子，没找到狗 |

结论：喘气、动得多这两种信号可用（喘气召回约四成、休息组零误报）；尾巴、身体高低只在侧面可信；
打哈欠、僵住、耳朵往后压没有足够的实拍样本验证，按内容库规则只作为"组合里的一项"使用（单个不会判成有压力信号，僵住除外）。

## 接入点

- `POST /body-check`：≤20 秒视频或一张照片，同步返回信号；忙时 429；上传文件分析完删除。
- 上传分析：`result.body`（整段每秒 3 帧）。
- 实时计时：快照里的 `body.counts`（最近 30 秒），结束结果里的 `body`。
- App：`lib/domain/body_signals.dart`（判定）、`lib/features/body/`（页面与部件）、`BodyRepository`（存在本机 video_analyses 表，skill_id = `__body__`，不同步）、AI 助理工具 `get_dog_state`。
