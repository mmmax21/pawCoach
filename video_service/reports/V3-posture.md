# V3：多角度姿态识别（2026-11-23）

## 结论

- **侧面**：沿用 B2 的规则（两段视频逐秒标注验证过），判"坐"的结果一律不改。
- **正面、斜前方、斜上方**：规则以前只能输出"看不清"，现在交给分类器补判。在 2086 张没见过的品种的照片上，"判对"从 32% 升到 84%（细节见下表）。
- **正上方俯拍**：部分可用。中文俯拍样片（毛团幼犬，一直坐着）能切出口令→坐下→保持的轮次，但仍有一半以上时间判不出（下面第 3 节），会被内容库的重拍门槛（看不清 > 50%）拦下。要可靠支持俯拍，需要俯拍训练数据或视觉大模型兜底（见"后续"）。

## 1. 数据与做法

- 数据：DogPoseCV（Hugging Face `stockeh/dog-pose-cv`，Stanford Dogs 子集，Apache-2.0）。标注 standing / sitting / lying，去掉 undefined。跑线上同一套 YOLOv8n + SuperAnimal 后，11,695 张找到狗：趴 3678、坐 2606、站 5411。数据在 `data/datasets/`（git 忽略，不进仓库）。
- 切分：按品种分组，20% 的品种只做测试（测试集 2086 张）。
- 两个分类器：
  - 关键点版 `posture_hgb.joblib`：39 个关键点的归一化坐标、两两距离、关节角 → scikit-learn 梯度提升树。训练增强：左右镜像、一半样本随机平面旋转。脚本 `scripts/v3_train_posture.py`。
  - 图像版 `posture_cnn.pt`：狗框裁图 192×192 → timm `mobilenetv3_large_100`（ImageNet 预训练）微调 6 轮。增强：任意角度旋转、透视、镜像、颜色、裁剪抖动。脚本 `scripts/v3_extract_dogpose.py`（抽关键点）、`scripts/v3_train_posture_cnn.py`。
- 合用（`pose/rules.py` 的 `merge_read`）：规则判"坐" → 不改；规则判不了 → 用分类器（概率达标才用）；规则判"站/趴"而分类器以 ≥0.85 判成另一个 → 用分类器；规则判"趴"必须分类器也判"趴"，否则当作看不清（规则的趴下条件从没有真实视频验证过）。有图像版时用图像版（概率门槛 0.75），否则用关键点版（0.6）。
- 时序：两段相同姿势之间不超过 1.5 秒的"看不清"当作姿势没变（`PoseRules.bridge_s`，保守值，未经逐秒标注验证）。

## 2. 照片测试集（2086 张，品种训练时没见过）

| 方法 | 判对 | 看不清 | 判错 |
|---|---|---|---|
| v3 之前：只用规则 | 667（32%） | 1227（59%） | 192（9%） |
| 规则 + 关键点版 | 1751（84%） | 103（5%） | 232（11%） |

| 分类器单独 | 准确率 | 概率 ≥0.7 时覆盖 / 准确率 |
|---|---|---|
| 关键点版（含旋转增强） | 88.4% | 90.7% / 92.0% |
| 关键点版（不做旋转增强） | 88.9% | 91.4% / 92.5% |
| 图像版 | 89.2% | 81.3% / 95.2% |

随机旋转测试图（模拟俯拍时狗在画面里朝向任意）：关键点版不做旋转增强 52.7%，做了 84.9%，所以保留旋转增强。

## 3. 中文俯拍样片（`狗狗训练-中文1.mp4`，17 秒，竖屏）

人工看帧：第 1 秒在走动，第 2–16 秒一直坐着（多次抬爪握手）。每 0.5 秒取一帧：

| 方法 | 判对 | 看不清 / 没找到狗 | 判错 |
|---|---|---|---|
| 只用规则 | 1 / 32 | 29 | 2 |
| 规则 + 关键点版 | 7 / 32 | 9 | **16**（坐判成趴或站） |
| 图像版（0.6 门槛） | 12 / 32 | 18 | 2 |

关键点版在俯拍幼犬上把"坐"高概率判成"趴"（腿被身体挡住），判错比看不清更糟，所以有图像版时离线和实时路径都不用关键点版。每 0.25 秒取帧、门槛 0.75 时图像版：判对 17、判错 5、看不清 34（共 56 帧）。测试时增强（镜像、90° 旋转平均）没有帮助。

整段分析（`analyze_video`，预检 + 姿势 + 转写 + 出声检测）：
- v3 之前：预检判"角度不对"直接要求重拍。
- 现在：预检通过；切出两轮可靠轮次（第 1 秒说"坐"→ 2.3 秒坐下；第 7.9 秒说"坐"→ 9.0–15.3 秒坐着），奖励时刻来自标记词"好"和出声检测。仍有 54% 时间看不清（超过内容库 50% 的重拍门槛，App 仍会提示重拍），且 6.4–7.0 秒有一段误判为趴。

## 4. 没做到 / 后续

- 侧面视频 dog3 已不在本机，重新下载被 YouTube 拦下，所以没能在侧面视频上复测合用后的效果；合用规则保证侧面判"坐"与之前完全一致，站 / 趴可能被分类器改判。
- 俯拍：需要俯拍角度的标注数据（自己拍几段逐秒标注即可微调图像版），或在本地模型判不了的帧上调用视觉大模型兜底（需要 API key，本机没有，没有实现）。
- 模型文件按 scikit-learn 1.9.1 / timm 保存；环境缺包或版本不兼容时自动退回只用规则（`POSTURE_MODEL=off` 也可手动关掉）。
