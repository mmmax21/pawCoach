# A6 三个 stub 实现

- 预计工时：1h（实际约 0.3h，三份 stub 逻辑都很薄）
- 验收命令：
  ```bash
  source .venv/bin/activate
  python -c "
  from pawcoach.pose.stub import StubPoseExtractor
  from pawcoach.audio.stub import StubAudioExtractor
  from pawcoach.reward.from_taps import TapRewardExtractor
  from pawcoach.video.probe import load_video
  from pawcoach.schema import MetaInfo
  v = load_video('data/raw/sample.mp4')
  m = MetaInfo(cues=['坐'], reward_taps=[5.2])
  p = StubPoseExtractor().extract(v)
  a = StubAudioExtractor().extract(v, m)
  r = TapRewardExtractor().extract(m, a)
  assert all(isinstance(x, list) for x in (p, a, r))
  print('A6 OK')
  "
  ```
- 验收结果：**通过**（三个 extractor 各可实例化并返回 list）
  - `StubPoseExtractor` → `[PoseSegment(0.0, 30.0, 'sit', 0.5)]`（整段一个 sit，conf 固定 0.5）
  - `StubAudioExtractor` → `cue@0.0 / marker@29.0 / release@29.5`（按视频时长相对放置，便于观察下游一轮）
  - `TapRewardExtractor` → `[RewardEvent(5.2, 'tap')]`（**从一开始就是真实现**，读 `meta.reward_taps`）
- 基线指标：无（stub 无模型）
- 遗留问题：无
- 下一步（调准）：无（A6 之后由 B 阶段换真实现，stub 保留作对照）

## 落地文件

| 文件 | 类 | 说明 |
|---|---|---|
| `pawcoach/pose/stub.py` | `StubPoseExtractor` | 返回整段一个 `sit`，conf=0.5 |
| `pawcoach/audio/stub.py` | `StubAudioExtractor` | 硬编码 cue/marker/release 各一，按时长相对放置 |
| `pawcoach/reward/from_taps.py` | `TapRewardExtractor` | 读 `meta.reward_taps` → `RewardEvent(source='tap')` |
