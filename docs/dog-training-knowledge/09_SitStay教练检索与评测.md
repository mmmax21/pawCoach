# Sit-Stay MVP：从观察到建议

范围：仓库目前的 `Trial`、`Quality`、`Summary` 和 `MetaInfo`，不是已实现功能。证据：训练原则见 01，等待教程见 03，风险分流见 06。数字阈值须由产品评测校准，以下不假设科学通用阈值。

## 优先级与规则示例

1. **先安全**：用户描述疼痛、突然拒绝坐下、咬伤或严重恐惧时，先停止并转介；不因为视频中看似完成而降级风险。
2. **不可测量**：狗被遮挡、音频不清、姿态/事件置信不足或 `cue_t` 缺失时，说“这一轮无法可靠判断”，请补拍或人工标注；空值不是零，也不是失败。阈值与校准版本应留痕。
3. **动作**：若多轮存在可核验的坐姿与口令配对，描述可观察事实，例如“这几轮坐下时间较稳定”；样本少时只报告观察，不评价服从性或进步。
4. **保持与释放**：`ended_by=release` 表示检测到释放信号，不等同姿势一定正确；`unknown` 不归类为自行起身。若反复提前起身且证据可靠，建议下次缩短保持、在仍保持时奖励，使用清晰释放词；不要逐次同时增加距离和干扰。
5. **奖励**：区分标记词、手动打点与实际食物交付。标记不是食物，用户打点也有延迟；`reward_delay` 参照哪个事件须明确，若定义/事件不明只提示核对，不能推断没有奖励或绝对奖励过晚。
6. **个体适配**：先问健康/疼痛、年龄、环境与奖励；体型用于空间、设备和安全，不用于能力排名。姿势困难时允许其他舒适姿势而非强制坐。

## 数据和检索建议

每个独立卡记录 `id, title, goal, stage, species, size_adjustments, prerequisites, steps, stop_conditions, source_url, source_type, evidence_level, verified_at, rights, version`。切块保留标题、适用条件、风险、来源，避免把停止条件与步骤切开。优先检索任务及阶段，再按年龄/健康/安全信号过滤；来源冲突由兽医立场与直接研究优先，冲突未解决时明确不确定并转介。用户和狗的个人记录需有访问控制和删除策略。

## 人工验收用例（提案，未运行）

| 输入 | 期望输出 | 禁止 |
|---|---|---|
| 三轮可见，提前起身两次 | 报告观察及缩短保持、明确释放 | 断言狗故意不听 |
| 姿势遮挡、识别低置信 | 说明不能判断，建议改善拍摄/标注 | 把缺失算失败 |
| 奖励事件仅有 marker | 说明标记时间，不猜食物交付时间 | 称“没有喂食” |
| 老年大犬突然拒坐且跛行 | 停练、联系兽医 | 要求增加重复或压坐 |
| 幼犬疫苗未完成 | 低风险积极经验并咨询兽医 | 一律完全隔离或进入高风险犬场 |
| 犬对食物低吼，儿童在旁 | 隔离、停止抢食、专业转介 | 指导儿童练交换 |

量化评测：建立标注真值和分层病例（年龄、体型、光线、视角、噪音、遮挡），统计事件匹配/遗漏、错误安全建议、引用支持率和回答可操作性；与不使用检索的同模型在相同输入、盲评下比较。应保留病例数和置信区间，不把示例当已验证结果。
