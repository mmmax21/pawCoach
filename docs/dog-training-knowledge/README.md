## 检索建议

优先按“训练目标 + 阶段 + 可观察行为 + 奖励/释放 + 失败处理 + 安全边界”切块。每个小节可作为独立 chunk；保留来源链接和证据标签，避免把建议误当作适用于所有犬只的定律。用户描述攻击、咬伤、严重恐惧、疼痛或突然行为改变时，应优先执行 `06_安全分流与专业转介.md`。

## 证据标签

- **事实**：由所列来源直接支持，来源链接紧邻内容。
- **实践建议**：根据多个来源整理出的可操作训练流程，不代表受控试验已验证每个细节。
- **待个体化**：受健康、成长阶段、环境、奖励偏好和既往学习史影响，应先观察再调整。

## 与现有 pawCoach 资料库的关系

本地仓库 `docs/datasets-and-papers.md` 与 `docs/pet-training-agent-technical-resources.md` 已覆盖较多视觉数据、动作识别、姿态估计及相关研究论文。本补充包面向“如何教宠物、如何安全地给建议”，补齐可检索的教学步骤和分流规则。它没有修改项目源码或原有研究文档。
