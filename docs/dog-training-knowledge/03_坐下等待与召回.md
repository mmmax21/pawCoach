# 坐下、等待与召回：分步训练卡

适用：基础家庭训练。检索词：坐下、等待、stay、释放词、召回、口令。

## 坐下

**准备**：安静、防滑地面；一小份狗愿意吃的奖励。老年犬、肥胖犬或疑似疼痛犬不应被反复引诱坐下，应先考虑健康与舒适度。

1. 站在狗面前，奖励放在鼻子附近，缓慢向头顶后方移动；狗自然坐下时标记并奖励。
2. 连续几次成功后加入口令“坐”，说一次，再做手势；狗坐下立刻标记奖励。
3. 逐渐减少手里可见的食物，用空手手势提示，完成后再从口袋取奖励。
4. 在不同房间重复，之后才加入轻微干扰。若狗后退、跳起或持续失败，降低手势幅度或回到更容易的位置。

## 等待（短暂停留）

等待由“姿势 + 可承受的时间/距离/干扰 + 清晰释放信号”组成。每次只增加一项。

1. 让狗坐下或站在舒适姿势，给口令“等”；先只停 1 秒，狗仍保持就标记奖励。
2. 说固定释放词（如“好，去吧”），鼓励狗离开原位。**释放词是任务结束信号**，与奖励口令区分也可以，但需全家一致。
3. 从 1 秒逐渐增加到 2、3 秒等；偶尔回到短时长。不要每次都要求更久。
4. 时间稳定后，逐步增加一步距离，再回到原位奖励；最后在安全环境逐步加入低强度干扰。
5. 狗提前起身时不责骂；平静重置，下一轮缩短一个难度维度。若连续失败，说明当前步长过大。

**重要区分**：等待不是“无论如何都不许动”。训练时需给狗清晰的起始与结束信号，休息和活动也属于正常需要。

## 召回

1. 从室内或围栏内 1–2 米开始，狗注意到你时用开心语气说一次“来”。
2. 后退几步吸引狗跑向你；狗到身边时标记并连续给几小份奖励。
3. 多数时候奖励后放狗回去继续嗅闻/玩耍；偶尔牵上牵引绳也给奖励。
4. 逐步加入距离与干扰。户外未稳定前使用长牵引绳并遵守当地规则；不要在未围栏环境测试可靠性。
5. 狗没来时避免追逐或重复喊叫；缩短距离、降低干扰、换更有价值的奖励。

## 观察记录

每轮记录：成功/尝试、坐下反应延迟、等待时长、提前起身次数、释放后离位、奖励类型、环境干扰。指标用于比较同一只狗的进展，不应跨体型或犬种直接排名。
