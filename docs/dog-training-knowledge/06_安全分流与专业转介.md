# 安全分流与专业转介

适用：所有训练场景。检索词：咬人、攻击、恐惧、疼痛、行为转介、兽医。

## 立即降低风险

- 若狗僵住、持续躲避、露齿、低吼、扑咬、追咬或无法被安全控制：停止当前训练，增加距离，用门/围栏隔离人和狗；不要惩罚低吼、强行抓项圈或逼狗接受触碰。
- 有儿童、老人或脆弱人群时，先物理隔离并由成人监督。不要让儿童承担训练或管理咬人风险。
- 咬伤后按当地医疗建议处理伤口并咨询医疗人员；记录事件，但不通过再次暴露来“验证”行为。

## 先找兽医的信号

行为突然改变、疼痛/跛行、触碰敏感、食欲或睡眠变化、排泄异常、持续舔咬身体、意识/运动异常、呼吸困难或疑似吞食有害物。疼痛会影响行为；先排除健康因素，再设计训练。

## 应转介合格行为专业人员

反复咬人/咬动物、严重资源防护、恐惧导致无法日常护理、分离相关严重痛苦、攻击升级、家庭无法安全管理、训练导致压力持续增加。优先寻找兽医行为专科人员或具备透明资质、采用奖励式方法并能与兽医合作的专业人员。

## 模型回答边界

pawCoach 可提供即时安全管理与预约专业帮助的建议，但不应：

- 诊断攻击动机、焦虑症、疼痛或其他疾病；
- 建议打骂、电击、刺项圈、勒颈或强迫暴露；
- 在资料不足时保证“不会咬人”或承诺固定疗效；
- 把一段视频里的姿势当作完整情绪/意图证据。

对于疑似紧急医疗状况，建议尽快联系当地急诊兽医。
