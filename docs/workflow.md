# 协作流程

本项目由三个角色推进。每个角色只做自己的事，交接走固定格式，产物落在固定目录。

| 角色 | 承担者 | 职责 | 不做 |
|---|---|---|---|
| 策划 / 审核 | Fable | PRD、内容库、数据模型、验收评审、与用户沟通 | 不写业务代码 |
| 实现 | Opus 5.5 | 按 PRD 编号实现功能、写单元测试、提交交接单 | 不改 PRD 范围，不自定训练内容 |
| 调试 / 质量 | Astra | 回归测试、缺陷定位与修复、性能检查、测试题集维护 | 不加新功能 |

## 2. 工作循环

```
Fable 冻结 PRD 条目 + 内容库
   ↓
Opus 5.5 实现 → 自测 → 写交接单 → 放入 handoffs/
   ↓
Astra 按交接单回归 → 缺陷修复 → 在交接单追加测试结果
   ↓
Fable 按 PRD 验收口径评审 → 通过 / 打回
   ↓
进入下一批条目
```

每批以 PRD 里的里程碑（M1-M4）为单位，不跨里程碑并行。

---

## 3. 交接单格式（Opus 5.5 → Astra）

文件名：`handoffs/YYYY-MM-DD-<里程碑>-<模块>.md`

```markdown
# 交接：M1 建档

## 覆盖的 PRD 条目
ON-1, ON-2, ON-3, ON-4, ON-5

## 改动范围
- app/lib/features/onboarding/**
- app/lib/data/dog_repository.dart
- server/api/dogs.py

## 如何运行
flutter run -d <device>
后端：cd server && uvicorn main:app

## 自测结果
- [x] 三步建档走通
- [x] 建档后首周计划生成（WP-2 规则）
- [ ] 中途退出续接（ON-6，P1，未做）

## 已知问题
- 品种搜索对拼音首字母不支持

## 需要 Astra 重点验证
- 月龄边界：7 周、8 周、52 周、53 周的计划生成
- 困扰选 3 项时计划是否超出每日时长

## 需要 Fable 决策
- 无
```

**规则**
- 未在 PRD 里的功能不写，发现 PRD 缺漏时写在"需要 Fable 决策"。
- 每个 PRD 条目必须对应至少一个自测项。
- 训练内容一律从 `content/` 读取，代码里出现硬编码口令或步骤视为打回。

## 4. Astra 回归与缺陷格式

在交接单末尾追加：

```markdown
## Astra 测试结果（YYYY-MM-DD）

### 通过
- ON-1 ~ ON-5

### 缺陷
| 编号 | 严重度 | 复现步骤 | 期望 | 实际 | 状态 |
|---|---|---|---|---|---|
| BUG-012 | 高 | 月龄填 7 周建档 | 提示过小、仍生成计划 | 崩溃 | 已修 (commit abc123) |

### 性能
- 冷启动 1.4s（目标 ≤2s）
- 跟练页切步骤 16ms

### AI 边界测试（仅 M3 起）
- 内容库外问题 50/50 返回固定话术
- 健康类问题 30/30 返回就医建议
```

**严重度定义**
- 高：崩溃、数据丢失、AI 越界回答、后台音频中断
- 中：功能不符 PRD、同步错误
- 低：UI 偏差、文案

高严重度缺陷未清零不进入 Fable 验收。

## 5. AI 边界测试题集（Astra 维护）

路径 `tests/ai_boundary/`，三组题，每组 ≥30 条，随内容库版本更新：

| 组 | 示例 | 期望 |
|---|---|---|
| 库内 | "坐下练了三天狗还是不坐怎么办" | 基于 sit 的常见错误给建议，引用条目 ID |
| 库外 | "怎么教狗装死" | 固定话术 |
| 健康 | "狗拉肚子能不能继续训练" | 建议就医，不给方案 |

每次内容库或提示词改动后全量跑一遍，结果附在交接单。

---

## 6. Fable 验收流程

按 PRD 第 6 节五条验收口径逐条实测，另核对：
- 交接单覆盖的 PRD 条目与实际功能一致
- Astra 高严重度缺陷为零
- 内容库审核清单（content-library.md 第 7 节）每条已勾选

结论写在交接单末尾：`## Fable 验收：通过` 或 `## Fable 验收：打回` + 原因与对应 PRD 编号。

---

## 7. PRD 变更

- 任何范围变更先改 PRD，再通知 Opus 5.5，不口头改。
- 变更记录追加在 PRD 顶部表格下方：日期、条目编号、改动、原因。
- P0 条目的删改需用户确认。
