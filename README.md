# PawCoach —— 宠物训练行业的 AI 助理训犬师

> 2026 上海黑客松 · 赛题：**给一个行业，造一位 AI 同事**

一个专业训犬师只能带十几个学员、一周见一次；幼犬却需要每天练、每天有人跟进。**PawCoach 里的 AI 助理训犬师**接过训犬师的日常跟进工作：它认识每一只狗，看得到训练记录和本周计划，按专业规则判断该练什么、能不能练、要不要调整，替主人把计划改好（主人点确认才生效）；遇到健康问题或超出能力的行为问题，就转给兽医或专业训犬师。

- **行业**：宠物训练服务（2–12 个月幼犬的正向训练）
- **岗位**：助理训犬师
- **形态**：Flutter App（Android / iOS），演示以 Android 为主。在线模式可以由手机直连模型，也可以经电脑上的 `server/` 转发；`server/` 同时负责家庭同步
- **演示日期**：2026 年 11 月 21 日

## 赛题对应

| 赛题要求 | PawCoach 怎么做到 |
|---|---|
| **具体行业、具体岗位** | 宠物训练服务 · 助理训犬师。工作内容：每天跟进训练进度、答疑、调整训练计划、识别风险并转介 |
| **有业务规则的工作** | 规则写在代码和内容库里，模型绕不过去：技能有周龄窗口和前置关系；一周 2 次"完全做到"算掌握、2 次"没做到"退回更基础的技能；每周目标有上限；只用正向训练方法；健康问题必须转兽医；问题行为出现特定信号要转训犬师 |
| **行业理解** | 结构化内容库（`content/`）：18 个技能（教程、跟练脚本、常见错误、成功标准）、9 类问题行为（诊断问答、方案、转介条件）、24 条常见问题，均整理自公开的正向训练资料并标注来源 |
| **外部工具调用** | AI 助理训犬师有 8 个业务工具：查看狗狗档案、训练记录、本周计划，检索内容库，按规则检查能不能练，提议加入计划，开始跟练，转介兽医 / 训犬师。实验功能里还能调用视觉 / 听觉感知服务（`video_service/`）实时测量训练动作 |
| **业务判断** | 模型先查事实再判断，例如"坐下的前置技能还没掌握，先练跟随零食"、"拒绝凶它，并说明原因和替代做法"、"低吼不止一次先问训犬师"；改计划前按规则校验，不满足时说明原因。实验功能"实时奖励计时"按内容库的阈值（奖励晚于坐下 1 秒）当场判断主人奖励是否太晚 |

### 和通用大模型有什么不同

| | 通用大模型 | PawCoach 的 AI 助理训犬师 |
|---|---|---|
| 认识你的狗 | 每次都要重新介绍 | 自动读取周龄、困扰、已掌握技能、全家统一的口令 |
| 知道练得怎么样 | 只能听你描述 | 直接看打卡、评分和连续天数，回答基于真实进度 |
| 能动手 | 只给一段文字 | 生成可确认的操作：加入本周计划、开始跟练、转介 |
| 可靠 | 可能编造、可能推荐惩罚 | 训练方法只来自内容库并标注出处；健康问题一律转兽医 |
| 闭环 | 问完就结束 | 周计划 → 跟练 → 打卡评分 → 周报 → 自动调整下周计划 |

## AI 助理训犬师怎么工作

```
主人提问
  │
  ├─ 健康拦截：涉及健康、疾病、用药、受伤 → 立即建议就医，不调模型
  │
  ├─ 模型决定调用哪些工具（最多 6 轮），工具在手机本机执行：
  │     查看狗狗档案 · 查看训练记录 · 查看本周计划 · 检索内容库
  │     按规则检查能不能练 · 提议加入计划 · 开始跟练 · 转介兽医 / 训犬师
  │
  ├─ 写操作只生成"确认卡片"；主人点确认时，按同一套业务规则重新校验后才写入计划
  │
  └─ 回答：结合这只狗的情况、给出可马上做的步骤、标注内容库出处，并显示"已查看"了哪些信息
```

**两种模式**（AI 教练页右上角切换）：

| | 离线（默认） | 在线 |
|---|---|---|
| 回答 | 内容库原文直出，不调模型 | AI 助理训犬师：调用工具、结合狗的情况回答 |
| 联网 | 不需要 | 需要连模型（见下面两种接法） |
| 健康问题 | 拦截，建议就医 | 同样先拦截，不交给模型 |

在线模式连模型有两种接法，在"我的"页面里配置：

| 接法 | 配置 | 适合 |
|---|---|---|
| **手机直连**（推荐演示用） | 我的 → **AI 模型直连**：填 API Key、接口地址（官方或兼容 Anthropic 格式的中转）、模型名，点"测试连接" | 不依赖电脑，带一部手机就能演示 |
| 经电脑转发 | 不填直连 key；电脑启动 `server/`，我的 → **服务器地址** 填电脑 IP | key 留在电脑上，手机里不存 |

两种接法下，Agent 循环、工具执行、健康拦截和业务规则校验都在手机上运行。数据库存在手机本机，不会整体上传；发给模型的只有这次提问里工具查到的那部分信息（例如狗的周龄、相关的几条训练记录）。在线请求失败时，App 会自动改用离线模式回答并提示，演示不会卡死。

### 演示流程（约 3 分钟）

1. 首页：今日保底任务一键开始 → 全屏跟练 → 表情评分 → 打卡庆祝。
2. AI 教练切到"在线"，问："剪指甲它就躲，帮我加个技能进计划。"
3. 画面上出现"查看狗狗档案 → 检索训练内容库 → 查看本周计划 → 按规则检查能不能练 → 准备调整计划"。
4. 回答结合这只狗的情况，下方出现"加入本周计划：全身触摸脱敏"确认卡片；点确认 → 回首页，本周目标多了这个技能。
5. 再问："它今天拉肚子还能练吗？" → 立即建议就医，不调模型。
6. 可选：同一个问题对比 ChatGPT 的回答。

详细设计、真机彩排结果和演示当天检查清单见 [`handoffs/2026-11-18-online-agent.md`](handoffs/2026-11-18-online-agent.md)。

## 功能一览

| 模块 | 能做什么 | 状态 |
|---|---|---|
| 建档 | 三步问卷：狗的信息 → 当前困扰 → 主人条件，完成后生成首周计划 | ✅ |
| 周计划 | 按月龄、已掌握技能、困扰、每日时长生成 2–4 个目标技能 + 每日保底任务（≤5 分钟）；周报与下周自动调整 | ✅ |
| 跟练 | 全屏分步引导、语音播报、响片按钮、倒计时圆环、户外高对比模式，切后台 / 锁屏继续 | ✅ |
| 记录打卡 | 表情评分、备注、连续打卡天数、打卡庆祝、历史记录 | ✅ |
| 技能树 | 成长路径：现在可以练 / 接下来解锁（写明还差什么）/ 已掌握；也可切换全图 | ✅ |
| AI 教练 | 课程内提问、问题行为诊断（追问 → 方案 → 一键加入计划）、常见问题；**离线 / 在线（AI 助理训犬师）两种模式** | ✅（在线需启动 `server/`） |
| 家庭共享 | 邀请码加入家庭，多台手机同步训练记录，任一成员打卡都算 | ✅（需启动 `server/`） |
| 徽章、养护日历 | 训练里程碑徽章，疫苗 / 驱虫提醒 | ✅ |
| 视频纠错 | 上传训练视频，自动指出"奖励太晚""口令重复"等常见错误；带取景框的拍摄引导 | 🚧 **敬请期待**（默认构建只显示入口，不可点） |
| 实时奖励计时 | 边练边显示：狗是否坐下、口令和奖励的时刻、奖励比坐下晚了多久，超过阈值当场变红并显示内容库原文 | 🧪 实验（默认隐藏，需要 `video_service/`；尚未在真机上验证） |

## 快速开始

### 1. 准备环境

| 需要 | 版本 / 说明 |
|---|---|
| Flutter | 3.50（`flutter --version`），Dart ≥ 3.6 |
| Android Studio | 带一台 Android 模拟器（AVD），或一部开了 USB 调试的安卓手机 |
| Python | 3.12+，启动 `server/` 时需要 |

> 如果终端里找不到 `flutter`，要把 Flutter 的 `bin` 目录加进 PATH，例如 `export PATH="$HOME/development/flutter/bin:$PATH"`。

### 2. 只运行 App（离线模式，单机就能体验大部分功能）

```bash
cd app
flutter pub get
flutter run            # 有多台设备时加 -d emulator-5554
```

不启动后端也能完整走：建档 → 周计划 → 跟练 → 打卡 → 周报 → AI 教练（离线，内容库直出）→ 徽章 / 养护提醒。

打开模拟器（把 `<AVD 名称>` 换成自己的，`emulator -list-avds` 可以查）：

```bash
~/Library/Android/sdk/emulator/emulator -avd <AVD 名称> &
```

### 3. 打开在线模式：手机直连（最简单）

App 里进 **我的 → AI 模型直连**，填好 API Key、接口地址和模型名，点 **测试连接**，再到 **AI 教练** 右上角切到 **在线**。不需要启动电脑上的任何服务。

> 演示构建为了方便，API Key 以明文保存在 App 的本机文件里（不进数据库、不同步）。正式发布前应改为系统钥匙串 / Keystore 存储。

### 3'. 打开在线模式：经电脑上的 `server/` 转发（也用于家庭同步）

```bash
cd server
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

按手上的条件选一种模型上游（详见 `server/README.md`），然后启动：

| 上游 | 设置 |
|---|---|
| Anthropic API key | `export ANTHROPIC_API_KEY=...` |
| 第三方中转（Anthropic 格式接口） | `export ANTHROPIC_BASE_URL=...`、`export ANTHROPIC_API_KEY=...`、`export FALLBACKS=off` |
| 本机已登录的 `claude` 命令行（较慢，仅测试） | `export CLI_UPSTREAM=1` |
| 不调模型的假上游（联调） | `export FAKE_UPSTREAM=1` |

```bash
.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000
```

- 验证：`curl localhost:8000/healthz`（`upstream` 字段显示当前上游）
- Android 模拟器里的 `10.0.2.2` 就是电脑本机，App 默认连 `http://10.0.2.2:8000`。
- App 里进 **AI 教练**，右上角切到 **在线**。
- 家庭共享：开两台设备各装一份 App。A 建档后进 **我的 → 家庭成员** 看 6 位邀请码；B 在建档第一屏点 **加入已有家庭**，输入邀请码。

### 4. 用真手机演示

1. 手机和电脑连**同一个 Wi-Fi**，电脑上按第 3 步启动后端；电脑防火墙需放行 8000 端口。
2. 打 debug 包（release 包不允许连局域网的 http 地址）并安装到手机：

```bash
cd app && flutter build apk --debug
```

3. 手机上进 **我的 → 服务器地址**，填电脑的局域网 IP 和端口（Mac 上 `ipconfig getifaddr en0` 可查，例如 `192.168.1.19:8000`），点 **测试连接**。换了 Wi-Fi 只需在这里改地址，不用重新打包。

> 部分手机（如 vivo）会拦截 `adb install`，可以 `adb push` 到手机的"下载"文件夹后在手机上点开安装。

### 构建参数一览

| 参数 | 默认 | 作用 |
|---|---|---|
| `SYNC_BASE_URL` | `http://10.0.2.2:8000` | 服务器地址的默认值（在线模式与家庭同步共用；App 里"我的 → 服务器地址"可以改） |
| `AI_ONLINE` | `false` | AI 教练默认是否在线模式（用户也可以在 AI 教练页随时切换） |
| `AI_MODE` | `library` | 旧版模型生成开关（M3），保留不用；在线模式请用 AI 教练页的开关 |
| `VIDEO_ANALYSIS` | `false` | 视频纠错与实时奖励计时开关。默认关闭（视频纠错入口显示"敬请期待"，实时计时不显示）；开发时设 `true` 打开 |
| `VIDEO_BASE_URL` | `http://10.0.2.2:8001` | 视频分析服务地址 |

用法：`flutter run --dart-define=参数=值`，多个参数重复写多次 `--dart-define`。

## 实验功能：视频纠错与实时奖励计时

两者都需要电脑上运行 `video_service/`（姿态模型 + 声音分析），默认构建里不开放。想试用：启动 `video_service/run.sh`，App 打包时加 `--dart-define=VIDEO_ANALYSIS=true`。

| | 视频纠错（录完分析） | 实时奖励计时（边练边看） |
|---|---|---|
| 做什么 | 识别狗"坐下 / 起身"的时刻和口令、奖励词，按内容库规则判断常见错误（坐下、短时等待、长时间等待），附时间证据 | 实时显示狗是否坐下、口令和奖励的时刻、奖励比坐下晚多久；超过内容库阈值当场变红，显示"奖励给得太晚"原文 |
| 怎么测口令和奖励 | Whisper 转写后按词表匹配 | 只判断"有没有出声"：坐下前出声算口令，坐下后第一声算奖励；也可以点屏幕上的"奖励"按钮 |
| 验证情况 | 合成视频与一段中文实拍测过；实拍中文口令识别不稳定 | 合成视频经真实 WebSocket 验证：奖励延迟 2.22 / 2.02 / 0.32 秒，真值 2.2 / 2.1 / 0.3 秒；**尚未在真机上运行** |
| 限制 | 只认侧面拍摄 | 只认侧面拍摄；周围有人说话、狗叫会被当成出声；手机同时开相机和麦克风是否可行未验证 |

详见 `handoffs/2026-11-19-M5-video.md`、`handoffs/2026-11-19-video-correction-v2.md`、`handoffs/2026-11-20-live-timer.md`。

## 安全说明（演示构建）

- 手机直连模型时，API Key 以明文存在 App 本机文件里；正式发布前应改用系统钥匙串 / Keystore。
- iOS 为了连局域网里的电脑放开了明文 http（`NSAllowsArbitraryLoads`），Android 的 debug 包同样允许明文 http；正式发布前应收紧为仅本地网络或改用 https。
- `server/` 没有鉴权和限流，只在本机 / 局域网演示使用。
